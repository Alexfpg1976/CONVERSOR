DESCRIPCION

En este emocionante desafío de programación, construimos nuestro propio Conversor de Monedas. Donde aprendimos a realizar solicitudes a una API de tasas de cambio, 
a manipular datos JSON y, finalmente, a filtrar y mostrar las monedas de interés, programado en JAVA.

El conversor lo compone un menu principal, que tienes 3 opciones, donde se validan todos los campos y posibles digitaciones erroneas del usuario

************** MENU PRINCIPAL **************
                
 1 - CONVERSION DE MONEDAS
 2 - VISUALIZAR HISTORIAL
 3 - SALIR
 
ELIJA UNA OPCION VALIDA
 
*********************************************

Y un Submenu que contiene 7 opciones con posiblilidad de regresar al menu principal, donde tambien se validan los campos  y posibles digitaciones erroneas del usuario, 
teniendo en cuenta que el programa intenta guiar al usuario, en todo su recorrido.
